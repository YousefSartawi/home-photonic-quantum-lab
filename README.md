# Home Photonic Quantum Lab

A self-directed experimental and software project exploring photonic quantum computing from first principles.

The project combines quantum computing theory, Python simulation, polarization optics, experimental measurement, and eventually genuine single-photon and two-photon quantum experiments.

## Current Stage

### Prototype 0 — Classical Polarization Trainer

Planned optical system:

Laser → Polarizer → HWP → QWP → PBS → Detectors → Computer

The objective is to experimentally study:

- polarization-encoded qubit mathematics
- quantum state preparation
- superposition and phase
- wave-plate transformations
- measurement bases
- Bloch-sphere rotations
- comparison between theoretical predictions and experimental measurements

> Prototype 0 uses classical light and is not a true single-photon quantum computer.

## Project Roadmap

### Stage 0 — Classical-light trainer
Learn polarization control, measurement and software integration.

### Stage 1 — Single-photon system
Develop a heralded single-photon platform using SPDC and single-photon detectors.

### Stage 2 — Two-photon system
Study two-photon interference, entanglement, Bell states and tomography.

### Stage 3 — Scaling Research
Investigate approaches including:

- polarization/path/time-bin hybrid encoding
- detector multiplexing
- qudits
- automated calibration
- integrated photonics

## Software

The project will use Python to model quantum states and optical transformations, automate data collection, analyse measurements and compare experimental results with theoretical predictions.
